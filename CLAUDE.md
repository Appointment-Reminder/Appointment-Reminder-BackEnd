## Agent skills

### Issue tracker

Issues and specs are local markdown files under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: one `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

## Git workflow

- Never add `Co-authored-by` or other attribution trailers to commits or PR bodies.
- Do implementation work on a new branch, never directly on `main`.
